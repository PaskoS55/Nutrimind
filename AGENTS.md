# AGENTS.md

## Назначение

Продолжать разработку NutriMind by Pasko как демонстрационного SaaS-продукта персонального питания. Расчётная архитектура `0.1.1-draft` принята только как основа для переноса.

## Обязательные ограничения

- Не публиковать и не развёртывать проект без прямого разрешения владельца.
- Не менять утверждённый визуальный стиль, логотип или тексты интерфейса без отдельной задачи.
- Не изменять `docs/NUTRIMIND_SURVEY_SPEC.md` без отдельного согласования.
- Сохранять девять разделов и ветвления из `data/survey-schema.json`.
- Не добавлять вопросы про средние шаги, бытовую активность, RPE и длительность каждой тренировки двойного дня без утверждения.
- Аллергии и медицинские ограничения проверять до рейтинга продуктов.
- Не ставить диагнозы и не подтверждать дефициты без соответствующих числовых анализов.
- Не включать автоматическое снижение энергии до утверждения safety-скрининга.
- Не использовать демонстрационные значения отчёта как рекомендации реальному человеку.
- Не добавлять секреты, токены, пароли или реальные медицинские данные в репозиторий.

## Источники истины

- Анкета: `docs/NUTRIMIND_SURVEY_SPEC.md` и `data/survey-schema.json`.
- Расчёты: `docs/CALCULATION_CORE_SPEC.md`.
- База продуктов: `docs/PRODUCT_DATABASE_SPEC.md`.
- Рекомендации: `docs/RECOMMENDATION_RULES_SPEC.md`.
- Тестовые сценарии: `docs/TEST_SCENARIOS.md`.
- Демонстрационные данные: `data/demo-athlete-profile.json` и `data/demo-report.json`.

При расхождении старого текста анкеты с правилами `0.1.1-draft` расчётные и safety-правила берутся из четырёх документов версии `0.1.1-draft`, при этом исходную анкету не переписывать молча.

## Проверки перед передачей изменений

```bash
npm ci
npm run build
npm test
```

Ожидается `31 passed / 0 failed / 0 skipped`. Дополнительно проверить отсутствие секретов и то, что приложение запускается без учётных данных Sites.

## Архитектурная оговорка

Текущий `app/page.tsx` — единый клиентский прототип. Полная девятираздельная анкета пока представлена структурированными данными и спецификацией, но не полностью подключена к UI. При дальнейшем переносе в отдельные маршруты сохранять внешний вид до согласования нового дизайна.
