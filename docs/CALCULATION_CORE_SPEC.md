# NutriMind by Pasko — Calculation Core Specification

Версия: `0.1.1-draft`  
Статус: архитектурная основа для проверки; не для публикации и реальных пользователей  
Зависимость: неизменяемая спецификация [`NUTRIMIND_SURVEY_SPEC.md`](./NUTRIMIND_SURVEY_SPEC.md)

## 1. Границы версии

Ядро создаёт воспроизводимый **расчётный стартовый ориентир**, а не измеренную потребность и не доверительный интервал. Оно:

- не ставит диагнозы;
- не подтверждает дефициты без числовых лабораторных данных;
- не меняет лечебную диету;
- не выдаёт числовые КБЖУ несовершеннолетним;
- не применяет автоматическое снижение энергии до утверждения safety-скрининга;
- показывает цепочку `ответ → правило → коэффициент → результат`.

Обязательная подпись результата:

> Расчётный стартовый ориентир. Значение необходимо проверить по фактическому рациону, динамике массы, нагрузке и самочувствию.

## 2. Входные данные

Используются только девять разделов утверждённой анкеты:

| Блок | Поля |
|---|---|
| Профиль | `audience`, `ageGroup` |
| Антропометрия | `age`, `sex`, `heightCm`, `weightKg` |
| Цель | `goal` |
| Спорт | `sport`, `level`, `sessionsPerWeek`, `sessionDurationMin`, `doubleDays` |
| Обычная активность | `activity` |
| Питание | `meals`, `proteinFrequency`, `produce`, `fishFrequency` |
| Самочувствие | `sleep`, `sleepQuality`, `energy`, `digestion` |
| Гидратация | `water`, `sweat`, `trainingDrink` |
| Безопасность и анализы | `allergies`, `intolerances`, `medical`, `medicalNotes`, `labs`, `labRecency` |

## 3. Вопросы PAL на отдельное согласование

Эти поля подготовлены, но **не добавлены в анкету и не используются**:

| Поле | Вопрос | Формат |
|---|---|---|
| `stepsAverage7d` | Среднее количество шагов за 7 дней | число / не знаю |
| `occupationalActivity` | Бытовая активность вне тренировок | сижу / стою / много хожу / физический труд / меняется |
| `sessionRpe` | Интенсивность тренировки | RPE CR10 |
| `doubleSession1DurationMin` | Длительность первой тренировки двойного дня | минуты |
| `doubleSession2DurationMin` | Длительность второй тренировки двойного дня | минуты |
| `doubleSession1Rpe` | RPE первой тренировки | 1–10 |
| `doubleSession2Rpe` | RPE второй тренировки | 1–10 |

До утверждения недостающие ответы не угадываются.

## 4. Предварительная валидация

1. Антропометрия должна быть числовой и технически допустимой.
2. `none` не может сочетаться с конкретным значением в том же поле.
3. Спортивная ветка требует уровень, частоту и длительность.
4. Обычная ветка требует `activity`.
5. Несовершеннолетний → `blocked_numeric_output`.
6. Нераспознанная аллергия → `blocked_food_recommendations`.
7. Медицинское ограничение → минимум `specialist_review`.
8. Цель снижения массы или изменения состава тела → `goal_reduction_disabled`.

## 5. Основной обмен

Для взрослых:

```text
мужчины: REE = 10 × масса(кг) + 6,25 × рост(см) − 5 × возраст(лет) + 5
женщины: REE = 10 × масса(кг) + 6,25 × рост(см) − 5 × возраст(лет) − 161
```

Неокруглённое значение хранится в аудите, интерфейсное округляется до `5 ккал`. Источник: [Mifflin et al.](https://pubmed.ncbi.nlm.nih.gov/2305711/).

## 6. PAL — демонстрационные пресеты

### Обычный пользователь

| Ответ `activity` | Типичный день / отдых | Тренировочный день | Двойной день |
|---|---:|---:|---:|
| Преимущественно сижу | 1,40 | нет данных | нет данных |
| Много хожу | 1,55 | нет данных | нет данных |
| Физически активная работа | 1,70 | нет данных | нет данных |
| 2–4 фитнес-тренировки/нед. | 1,50 | 1,65 | нет данных |

### Спортсмен

| Уровень | День отдыха | Одна тренировка | Две тренировки |
|---|---:|---:|---:|
| Любительский | 1,50 | 1,70 | 1,90 |
| Соревновательный | 1,55 | 1,85 | 2,10 |
| Профессиональный | 1,60 | 2,00 | 2,25 |

Ограничения:

- профессиональный статус не доказывает конкретный PAL;
- пресеты не учитывают шаги, бытовую активность, RPE, климат и измеренный расход;
- тренировочные калории поверх PAL повторно не прибавляются;
- итоговый PAL ограничивается `1,40–2,40` и округляется до двух знаков;
- для одной спортивной тренировки: `≤45 мин → −0,05`, `46–90 мин → 0`, `>90 мин → +0,10`;
- для двойного дня модификатор длительности равен нулю, поскольку длительность каждой сессии пока неизвестна;
- двойной день получает `double_duration_unknown`.

PAL определяется как `TEE / BMR`; пресеты находятся внутри общих категорий FAO, но не являются измерением: [FAO Human Energy Requirements](https://www.fao.org/4/y5686e/y5686e07.htm).

## 7. Расчётный стартовый ориентир энергии

```text
EnergyStart_raw = REE_unrounded × PAL_demo
EnergyStart = округление_50(EnergyStart_raw)
```

Результат показывается одной центральной величиной с предупреждением об ограниченности. Интерфейс не называет его точной потребностью или статистическим интервалом.

## 8. Цели

| Цель | Действие версии 0.1.1 |
|---|---|
| Результативность и восстановление | коэффициент 1,00 |

```text
Правило → SAFETY_WEIGHT_REDUCTION_SCREEN_REQUIRED

Результат → ориентир поддержания + предложение пройти скрининг
```

## 9. Safety-скрининг на отдельное утверждение

До его утверждения автоматическое снижение энергии остаётся выключенным.

| Проверка | Предлагаемый формат | Действие |
|---|---|---|
| Беременность | да / нет / не уверен(а) / не применимо | да/не уверен → blocked |
| Грудное вскармливание | да / нет / не применимо | да → blocked |
| Низкая масса тела | BMI + клиническая оценка | BMI ниже 18,5 → blocked |
| Недавнее непреднамеренное снижение | кг, период, намеренность | значимое снижение → blocked |
| История РПП/нарушенного пищевого поведения | да / нет / предпочитаю не отвечать | да/не отвечать → blocked |
| Ограничительные или компенсаторные практики | да / нет | да → blocked |
| Возможные признаки низкой энергетической доступности | структурированный список | значимый признак → specialist review |

Скрининг учитывает повторные костные стрессовые повреждения, нарушения цикла, снижение либидо, устойчивое падение работоспособности, частые болезни, выраженную усталость, головокружения/обмороки и компенсаторные тренировки. Это не диагноз. Источники: [NICE NG69](https://www.nice.org.uk/guidance/NG69/chapter/recommendations), [NICE CG32](https://www.nice.org.uk/guidance/cg32/chapter/Recommendations), [IOC REDs 2023](https://bjsm.bmj.com/content/57/17/1073).

## 10. Три математически согласованных сценария КБЖУ

Сценарии предназначены для проверки чувствительности планирования, а не для заявления о точной погрешности:

```text
Energy_lower   = округление_50(EnergyStart × 0,94)
Energy_central = EnergyStart
Energy_upper   = округление_50(EnergyStart × 1,06)
```

### Планировочные коэффициенты

| Профиль | Белок |
|---|---:|
| Обычный взрослый | 1,2–1,6 г/кг |
| Спортсмен-любитель | 1,6–1,8 г/кг |
| Соревновательный | 1,7–2,0 г/кг |
| Профессиональный | 1,8–2,0 г/кг |

Жиры: нижний сценарий `0,9 г/кг`, центральный `1,0`, верхний `1,1`, но не менее `20%` энергии. При заболевании почек или релевантном medical flag коэффициент белка не применяется.

### Формула каждого сценария

```text
Protein_s = округление_0,1(weightKg × proteinCoefficient_s)
Fat_s = округление_0,1(max(weightKg × fatCoefficient_s, Energy_s × 0,20 / 9))
Carb_s = округление_0,1((Energy_s − Protein_s × 4 − Fat_s × 9) / 4)

MacroEnergy_s = Protein_s × 4 + Fat_s × 9 + Carb_s × 4
Deviation_s = MacroEnergy_s − Energy_s
```

Обязательное условие:

```text
abs(Deviation_s) ≤ 0,5 ккал
```

Если условие не выполняется или углеводы отрицательны, сценарий получает `macro_scenario_needs_review`.

### Демонстрационный пример

Мужчина, 28 лет, 189 см, 86 кг, профессиональный спортсмен, одна тренировка 90 минут:

```text
REE = 1906,25 ккал
PAL_demo = 2,00
EnergyStart = округление_50(3812,5) = 3800 ккал
```

| Сценарий | Энергия | Белок | Жиры | Углеводы | MacroEnergy |
|---|---:|---:|---:|---:|---:|
| Нижний | 3550 | 154,8 г | 78,9 г | 555,2 г | 3550,1 |
| Центральный | 3800 | 163,4 г | 86,0 г | 593,1 г | 3800,0 |
| Верхний | 4050 | 172,0 г | 94,6 г | 627,7 г | 4050,2 |

Каждая строка математически замкнута. Таблица не утверждает, что реальный расход находится между крайними значениями.

## 11. 14-дневная калибровка

Минимальное окно наблюдения — `14 дней`:

- утренняя масса минимум 4 раза в неделю;
- 7-дневная скользящая средняя;
- фактический рацион минимум 10 дней из 14;
- тип и длительность тренировок;
- энергия, сон, восстановление и пищеварение;
- измеренный расход при наличии; носимое устройство — только вспомогательный тренд.

```text
данных меньше 14 дней или рацион учтён неполно
→ insufficient_data

масса стабильна, рацион учтён, самочувствие приемлемо
→ calibrated_anchor = median(actual_intake_kcal)

динамика расходится с целью или ухудшается самочувствие
→ proposed_step ≤ 5% текущего ориентира
→ review_before_apply

medical/safety flag, возможные признаки LEA или противоречивые данные
→ automatic_correction = blocked
→ specialist_review
```

Система не переводит изменение массы напрямую в «точные калории» и не корректирует энергию ежедневно.

## 12. Гидратация

В отчёте разделяются четыре величины.

### 12.1. Общее поступление воды

`total_water` включает воду из пищи и напитков:

```text
TotalWaterStart_L = weightKg × 35 мл / 1000
```

Это демонстрационный ориентир. EFSA-ориентиры общего поступления также включают воду пищи: [EFSA Water](https://efsa.onlinelibrary.wiley.com/doi/10.2903/j.efsa.2010.1459).

### 12.2. Вода из напитков

Ответ `water` трактуется как самооценка напитков: `<1,5`, `1,5–2`, `2–3`, `>3 л`. Его нельзя вычитать из total water без оценки воды из пищи.

### 12.3. Дополнительная тренировочная жидкость

```text
TrainingFluidStart_low  = trainingHours × 0,4 л
TrainingFluidStart_high = trainingHours × 0,8 л
```

Для двойного дня:

```text
DoubleDurationHours =
  (doubleSession1DurationMin + doubleSession2DurationMin) / 60
```

Пока двух длительностей нет, одну длительность запрещено удваивать. Статус: `double_training_fluid_insufficient_data`.

### 12.4. Индивидуальный sweat rate

```text
SweatLoss_L =
  preExerciseWeightKg − postExerciseWeightKg
  + fluidConsumedL − urineProducedL

SweatRate_L_per_h = SweatLoss_L / sessionDurationHours
```

В двойной день sweat rate рассчитывается отдельно для каждой сессии. Источник: [ACSM Exercise and Fluid Replacement](https://pubmed.ncbi.nlm.nih.gov/17277604/).

## 13. Медицинские формулировки

- название анализа без числового результата не подтверждает дефицит;
- симптомы не превращаются в диагноз;
- разрешено: «возможный риск недостаточного поступления»;
- разрешено: «стоит обсудить со специалистом»;
- запрещены подтверждённые диагнозы и дефициты без достаточных данных.

## 15. Критерии приёмки

- энергия названа стартовым ориентиром;
- понижающие цель множители не применяются;
- PAL подписан как демонстрационный;
- каждый сценарий КБЖУ имеет отклонение не более `0,5 ккал`;
- двойной день не удваивает одну длительность;
- корректировка требует 14-дневного окна;
- исходная анкета этим документом не меняется.
